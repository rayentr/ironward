Documentation

Ironward is a modular security toolkit built for modern development workflows. It provides a comprehensive set of scanners designed to be fast, privacy-focused, and deeply integrated into your IDE via the Model Context Protocol (MCP).

Installation

The fastest way to use Ironward is via npx, which requires no permanent installation:

npx ironward scan .

To install the CLI globally:

npm install -g ironward
ironward --help

MCP Configuration

Ironward shines when used inside MCP-compatible editors like Cursor, Claude Code, or VS Code. Add the following to your configuration:

{
  "mcpServers": {
    "ironward": {
      "command": "npx",
      "args": ["-y", "ironward@latest"],
      "env": {
        "ANTHROPIC_API_KEY": "your-key-here"
      }
    }
  }
}

Offline Scanners

These tools run entirely on your local machine and do not require an AI API key or network access (except for vulnerability database lookups).

scan_for_secrets

Offline

Scans your source code for over 665 pattern families of hardcoded secrets. It covers all major cloud providers, payment gateways, and web3 wallets.

Key Features:

  • Pattern-based discovery for known token formats.
  • Shannon entropy analysis for high-entropy "mystery" strings.
  • Automatic redaction of discovered secrets in reports.

scan_code

Offline

Performs static analysis using a library of 374 rules. It targets the "vibe stack" (Next.js, Supabase, Prisma) and general backend security.

npx ironward scan-code ./src --exploit

scan_deps

Offline + API

Checks your package.json, requirements.txt, and other manifests against the OSV.dev vulnerability database.

Use --full to enable behavior analysis (scanning node_modules for malware) and reputation scoring.

scan_url

Offline

Probes a live URL for misconfigurations. It checks headers (CSP, HSTS), TLS expiry, and looks for common accidental file exposures like .env or .git.

scan_docker

Offline

Audits Dockerfiles and Docker Compose files for dangerous defaults like running as root or using privileged: true.

scan_k8s

Offline

Scans Kubernetes manifests for over-privileged pods, missing resource limits, and hardcoded secrets in environment variables.

scan_infra

Offline

Audits Terraform and CloudFormation templates for cloud misconfigurations like public S3 buckets or open security groups.

scan_github

Offline

Checks GitHub Action workflows for ACE vulnerabilities (Arbitrary Code Execution) via pull_request_target and expression injection.

AI-Powered Scanners

These tools use Large Language Models to find complex logic flaws that static patterns might miss. They require an ANTHROPIC_API_KEY or equivalent.

scan_auth_logic

AI Powered

Uses reasoning models to find backwards auth checks, missing ownership verification, and bypassable middleware logic.

scan_sqli

AI Powered

Analyzes how queries are constructed to find SQL injection vulnerabilities across multiple languages, including cases where ORM raw() methods are misused.

scan_xss

AI Powered

Finds Cross-Site Scripting (XSS) in frontend frameworks (React, Vue, Svelte) and backend templates, accounting for existing sanitization logic.

scan_idor

AI Powered

Flags Insecure Direct Object References by identifying routes that accept an ID but fail to verify if the requesting user owns that resource.

fix_and_pr

AI Powered

The ultimate automation tool. It takes a security finding, generates a surgical fix, verifies the fix by re-running the scanner, and opens a Pull Request on GitHub.

Global Flags

Common options available across most CLI commands:

  • --format json|sarif|text — Change the output format.
  • --verbose — Show low-confidence findings and detailed logs.
  • --no-cache — Force a fresh scan, bypassing local cache.
  • --offline — Skip all network-dependent features.
