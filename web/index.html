MCP server · CLI · VS Code extension

Security scanning for the vibe coding era.

Ironward is an open-source Model Context Protocol server and CLI that finds hardcoded secrets, auth bugs, SQL injection, XSS, IDOR, and vulnerable dependencies — and opens a fix PR for any finding. Runs inside Cursor, Claude Code, and VS Code.

Get Started Read Documentation View on GitHub → 
// ~/.cursor/mcp.json
{
  "mcpServers": {
    "ironward": {
      "command": "npx",
      "args": ["-y", "ironward@latest"],
      "env": { "ANTHROPIC_API_KEY": "sk-ant-..." }
    }
  }
}
# one shot
claude mcp add ironward -- npx -y ironward@latest
// .vscode/mcp.json
{
  "servers": {
    "ironward": {

  }

# scan without any IDE setup — no API key needed
npx ironward scan ./src
npx ironward scan-secrets ./src
npx ironward scan-code ./src
npx ironward scan-deps package.json
npx ironward scan-url https://example.com
ANTHROPIC_API_KEY is only needed for AI-backed tools. Five tools work fully offline.

Why Ironward?

01
Offline-first.

Core scanners run with zero network. Bring an API key only when you want AI reasoning or automated fixes. Your code stays on your machine.

02
Actionable Fixes.

Ironward doesn't just point at problems; it understands them. fix_and_pr handles the surgical replacement and verification for you.

03
Model Agnostic.

Use Claude, GPT-4, Gemini, Groq, or a fully-local Ollama stack. You own your keys and your privacy.

04
Native Workflow.

Designed for the MCP era. Works seamlessly in Cursor, Claude Code, and VS Code. It feels like part of your editor, not a separate chore.

Zero-Install Usage.

Run any scanner instantly using npx. Perfect for CI/CD or quick audits.

# Run all offline scanners
npx ironward scan .

# Scan for secrets with high-confidence patterns
npx ironward scan-secrets ./src

# Audit dependencies for malware and CVEs
npx ironward scan-deps --full

# Start the security dashboard
npx ironward api-server
